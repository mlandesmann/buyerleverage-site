# buyerleverage.net

Static version of the BuyerLeverage website, published with GitHub Pages.

- Each page lives in its own folder as `index.html` (e.g. `partners/index.html`), so addresses match the old WordPress site.
- Shared styling: `assets/style.css`. Images: `assets/img/`.
- `CNAME` tells GitHub Pages to serve the site at buyerleverage.net.
